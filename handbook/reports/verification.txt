10. AMM constant-product fee model and pool drain
-------------------------------------------------
Model: selling m tokens into a pool with token reserve x and quote reserve y
returns dy = gamma*m*y/(x + gamma*m). If y is large, the fraction of the
quote reserve removed is gamma*m/(x + gamma*m).
x=1,000,000, m=1,000,000 -> gamma*m/(x+gamma*m) = 49.924887330996%
x=1,000,000, m=10,000,000 -> gamma*m/(x+gamma*m) = 90.884229717411%
x=1,000,000, m=1,000,000,000 -> gamma*m/(x+gamma*m) = 99.899799599198%
x=1,000,000, m=1,000,000,000,000 -> gamma*m/(x+gamma*m) = 99.999899699198%
PASS  m=x drain fraction: '49.924887330996%'
This is a model with integer-rounding ignored. It does not predict a real
pool without reserves, decimals, and router behavior.
